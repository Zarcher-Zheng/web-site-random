# 隨機抽選助手 (Random Picker)

一個基於 HTML/CSS/JS 的現代化隨機抽選工具，專為 GitHub Pages 部署設計。

## 功能特點

- **響應式設計**：完美支援手機與桌機瀏覽。
- **簡約美觀**：採用 Glassmorphism 玻璃擬態設計風格。
- **自動存檔**：內容會自動儲存在瀏覽器 local storage，下次開啟時內容還在。
- **快速效能**：純靜態開發，無需後端，開啟速度極快。

## 如何部署到 GitHub Pages

1. **建立 GitHub 儲存庫**：
   - 在 GitHub 上建立一個新的儲存庫。
   - 將本專案的所有檔案 (`index.html`, `style.css`, `script.js`) 推送到該儲存庫。

2. **啟用 GitHub Pages**：
   - 點擊儲存庫上方的 **Settings** (設定)。
   - 在左側選單點擊 **Pages**。
   - 在 **Build and deployment** 下方的 **Branch** 選項，選擇 `main` 分支並點擊 **Save**。

3. **瀏覽你的網站**：
   - 等待幾分鐘後，GitHub 會提供一個網址（例如：`https://your-username.github.io/your-repo-name/`）。
   - 現在你可以透過手機或電腦分享這個連結了！

## 本地預覽

直接在瀏覽器中開啟 `index.html` 即可立即使用。
